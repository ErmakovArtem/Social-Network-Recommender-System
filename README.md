# Social-Network-Recommender-System

Персонализированная рекомендательная система постов в социальной сети

## Цель проекта
Построить и развернуть рекомендательную систему, которая на основе исторических данных о поведении пользователей в социальной сети формирует персонализированный список из Top‑N релевантных постов для конкретного пользователя в заданный момент времени, обеспечивая при этом приемлемую точность рекомендаций и стабильную работу сервиса в продуктовой среде.

## Экономический эффект проекта
Увеличение конверсии в целевые действия, что связано с ростом hitrate@N.

## Решение

1. **Выгрузка и подготовка данных:** извлек данные из PostgreSQL и привел их к аналитическому виду

2. **Извлечене фичей**: проанализировал данные постов и пользователей, на основе существующей в них физики сформировал фичи

3. **Обучение модели**: на основе поставленной задачи выбрал метрику (Roc-Auc) и подходящую под данные модель (CatBoost)

4. **Результаты и выводы**: в результате обучения достингуто необходимое значение продуктовой метрики hitrate@N

5. **Пайплайн**: построил пайплан для работы рекомендательной системе в продакшене

## Инструменты
Python, SQL, Numpy, Pandas, Matplotlib, Scikit-learn, CatBoost, LightGBM, XGBoost, Pytorch, Huggingface, BERT, EDA, RecSys, NLP

## Описание проекта
Построение рекомендательной системы: от выгрузки данных из PostgreSQL до развёртывания сервиса, который возвращает персонализированные рекомендации (список релевантных постов для пользователя).
